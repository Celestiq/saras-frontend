# Assets Directory

This directory contains placeholder images for the How It Works section.

## Required Images

### Persona Images
- `persona-pm.png` - Product Manager persona image
- `persona-researcher.png` - Researcher persona image  
- `persona-diy.png` - DIY Enthusiast persona image
- `persona-student.png` - Student persona image

### Roadmap Images
- `roadmap-pm.png` - PM roadmap visualization
- `roadmap-researcher.png` - Researcher roadmap visualization
- `roadmap-diy.png` - DIY roadmap visualization
- `roadmap-student.png` - Student roadmap visualization

### Option Images
- `option-newsletter.png` - Newsletter option visualization
- `option-ebook.png` - Ebook option visualization

## Current Status

## Usage
Images should be imported and used in the HowItWorks component:

```tsx
import personaPmImage from '@/app/assets/persona-pm.png';
import roadmapPmImage from '@/app/assets/roadmap-pm.png';
// etc.
```
